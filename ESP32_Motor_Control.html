🌉 Bridge Server Solution

This web app connects to a Node.js bridge server that communicates with your UnLateBoard.

Setup Instructions:

  1. 📥 Install Node.js on your computer
  2. ⚡ Run: npm install (in the same folder as these files)
  3. 🚀 Run: npm start (starts the bridge server)
  4. 🌐 Connect this web app to localhost:3000

The bridge server will connect to your UnLateBoard and relay commands!
